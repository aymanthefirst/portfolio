# Ayman El Harake — Portfolio

**Live site:** [aymanthefirst.github.io/portfolio](https://aymanthefirst.github.io/portfolio/)

Java developer (Spring Boot, APIs, microservices). Former Alfresco and ESG Global. Side projects with public demos on the site.

## Stack

Next.js · React · TypeScript · Tailwind CSS · static export · GitHub Pages

## Local dev

```bash
npm install
npm run dev
```

Open [http://localhost:3000/portfolio](http://localhost:3000/portfolio)

## Deploy

```bash
npm run build
npm run deploy:pages
```
